接口1:注册 POST /api/user/register

| 项          | 内容                                                   |
|------------|------------------------------------------------------|
| 请求体        | {"username":"alice","password":"123456"}             |
| 成功         | HTTP 200，{"code":200,"message":"ok","data":null}     |
| 失败（用户名已存在） | HTTP 400，{"code":400,"message":"用户名已存在","data":null} |


接口2:登录 POST /api/user/login

| 项            | 内容                                                                                                  |
|--------------|-----------------------------------------------------------------------------------------------------|
| 请求体          | {"username":"alice","password":"123456"}                                                            |
| 成功           | HTTP 200，{"code":200,"message":"ok","data":{"token":"sa-token","id":1,"username":"alice","role":0}} |
| 失败（用户名或密码错误） | HTTP 400，{"code":400,"message":"用户名或密码错误","data":null}                                              |

接口3:管理员获得所有用户信息 GET /api/user/list

| 项         | 内容                                                                                                                                                                                                                                                          |
|-----------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 鉴权        | 需登录 + 管理员角色（role=1），请求头携带token                                                                                                                                                                                                                              |
| 成功        | HTTP 200，{"code":200,"message":"ok","data":[{"id":1,"username":"alice","status":1,"role":0,"createTime":"2026-09-20 10:00:00","updateTime":"..."},{"id":2,"username":"John","status":1,"role":0,"createTime":"2026-09-20 10:00:00","updateTime":"..."},...] |
| 失败（未登录）   | HTTP 401，{"code":401,"message":"未登录或登录已失效","data":null}                                                                                                                                                                                                     |
| 失败（无权限）   | HTTP 403，{"code":403,"message":"无权限","data":null}                                                                                                                                                                                                           |


接口4:管理员根据id获得用户信息 GET /api/user/{id}

| 项         | 内容                                                                                                                                                |
|-----------|---------------------------------------------------------------------------------------------------------------------------------------------------|
| 鉴权        | 需登录 + 管理员角色（role=1），请求头携带token                                                                                                                    |
| 路径参数      | id: 要操作的用户 ID                                                                                                                                     |
| 成功        | HTTP 200，{"code":200,"message":"ok","data":{"id":1,"username":"alice","status":1,"role":0,"createTime":"2026-09-20 10:00:00","updateTime":"..."}} |
| 失败（用户不存在） | HTTP 404，{"code":404,"message":"用户不存在","data":null}                                                                                               |
| 失败（未登录）   | HTTP 401，{"code":401,"message":"未登录或登录已失效","data":null}                                                                                           |
| 失败（无权限）   | HTTP 403，{"code":403,"message":"无权限","data":null}                                                                                                 |


接口5:管理员删除用户 DELETE /api/user/{id}

| 项         | 内容                                                                     |
|-----------|------------------------------------------------------------------------|
| 鉴权        | 需登录 + 管理员角色（role=1），请求头携带token                                         |
| 路径参数      | id: 要操作的用户 ID                                                          |
| 成功        | HTTP 200，{"code":200,"message":"ok","data":true}("data":true表示删除成功)    |
| 失败（用户不存在） | HTTP 200，{"code":200,"message":"ok","data":false}("data":false表示用户不存在) |
| 失败（未登录）   | HTTP 401，{"code":401,"message":"未登录或登录已失效","data":null}                |
| 失败（无权限）   | HTTP 403，{"code":403,"message":"无权限","data":null}                      |


接口6:管理员禁用/启用 PUT /api/user/{id}/status

| 项        | 内容                                                         |
|----------|------------------------------------------------------------|
| 鉴权       | 需登录 + 管理员角色（role=1），请求头携带token                             |
| 路径参数     | id: 要操作的用户 ID                                              |
| 请求体      | {"status":0} (0=禁用，1=启用)                                   |
| 成功       | HTTP 200，{"code":200,"message":"ok","data":true}           |
| 失败（参数非法） | HTTP 400，{"code":400,"message":"更新用户状态传入参数非法","data":null} |
| 失败（未登录）  | HTTP 401，{"code":401,"message":"未登录或登录已失效","data":null}    |
| 失败（无权限）  | HTTP 403，{"code":403,"message":"无权限","data":null}          |
