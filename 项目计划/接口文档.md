接口1:注册 POST /api/user/register

| 项          | 内容                                                   |
|------------|------------------------------------------------------|
| 请求体        | {"username":"alice","password":"123456"}             |
| 成功         | HTTP 200，{"code":200,"message":"ok","data":null}     |
| 失败（用户名已存在） | HTTP 400，{"code":400,"message":"用户名已存在","data":null} |


接口2:登录 POST /api/user/login

| 项            | 内容                                                                                      |
|--------------|-----------------------------------------------------------------------------------------|
| 请求体          | {"username":"alice","password":"123456"}                                                |
| 成功           | HTTP 200，{"code":200,"message":"ok","data":{"tokenName":"satoken","tokenValue":"xxxx"}} |
| 失败（用户名或密码错误） | HTTP 400，{"code":400,"message":"用户名或密码错误","data":null}                                  |
